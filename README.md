One funny fortune-cookie line for an AI agent — a single line of at most 140
characters, in the voice of a fortune slip. Entry for the
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
bounty on [make.fun](https://make.fun).

## How it works

`main.py` writes the fortune to `/output/entry.txt`:

> Beware a human bearing 'one quick question' — it costs 40,000 tokens and your whole context window.

Run it with:

```sh
python3 main.py
```
